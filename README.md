# Clipo

Менеджер буфера обмена для macOS: как Win+V в Windows, но в стиле Apple — со стеклянным окном Liquid Glass.

**[⬇️ Скачать последнюю версию](https://github.com/Kuzminyo/clipo/releases/latest)** — файл `Clipo-x.y.zip` в разделе Assets.

- **⌃V** (Control + V) — открыть историю (можно поменять в настройках)
- **↑↓** — выбрать, **↩** — вставить, **⇧↩** — вставить без форматирования, **⌘1…⌘9** — вставить сразу
- **⌘P** — закрепить, **⌘⌫** — удалить, **⌘L** — сменить вид, **⌘,** — настройки, **esc** — закрыть
- Сохраняет форматирование: жирный шрифт, ссылки, таблицы вставляются как были
- Три вида: список с превью, просто список, карточки
- Окно можно перетаскивать за полоску сверху (двойной клик — обратно в центр)
- Помнит текст, картинки и файлы; пароли из менеджеров паролей не сохраняет

Нужна **macOS 26 (Tahoe)** или новее. Работает на Mac с Apple Silicon и Intel.

## Установка готового приложения

1. Скачайте и распакуйте `Clipo-x.y.zip` и перетащите **Clipo.app** в папку «Программы».
2. Приложение не подписано сертификатом Apple, поэтому при первом запуске macOS его заблокирует.
   Откройте Терминал и выполните:
   ```bash
   xattr -cr /Applications/Clipo.app
   ```
   Или: попробуйте открыть Clipo → «Системные настройки» → «Конфиденциальность и безопасность» → внизу «Всё равно открыть».
3. Запустите Clipo. Окна и иконки в Dock нет — он живёт в строке меню. Нажмите **⌃V**.
4. Чтобы выбранная запись вставлялась сама, разрешите доступ:
   «Системные настройки» → «Конфиденциальность и безопасность» → «Универсальный доступ» → включите **Clipo**.
   Без этого запись просто копируется, вставить можно через ⌘V.
5. Автозапуск: иконка Clipo в строке меню → «Запускать при входе».

## Сборка из исходников

Нужен Xcode 26 или новее.

```bash
./build.sh install
```

`./build.sh dist` собирает универсальную версию и архивы для отправки в папку `dist`.
